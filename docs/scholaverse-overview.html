🏰 vm-web-server

  • FastAPI + Jinja2 + HTMX + Tailwind
  • SQLite + SQLAlchemy（async）
  • 套件管理：uv
  • 學生端 12+ 路由／管理端 11 頁
  • 16-bit 像素奇幻 RPG 介面（zh-TW）

⚡ vm-ai-worker

  • Ollama qwen2.5-14b（prompt 生成）
  • sd-cli + Z-Image-Turbo（Q8_0 GGUF）
  • 雲端：OpenAI gpt-image-2（generate／edit）
  • asyncio.Queue(50)・job timeout 600s
  • Conda 環境（CUDA 相依）

📚 vm-db-storage

  • FastAPI + aiosqlite（WAL，直接 SQL 無 ORM）
  • images＋generation_metadata 兩張表
  • 上傳僅限 ai-worker、讀取僅限內網兩台 VM
  • 路徑防穿越・冪等覆寫（INSERT OR REPLACE）
  • 雲端 metadata 7 欄位（backend、fallback…）

六個單元，六段養成

每個學習單元對應課程的一個 AI 主題，也對應角色的一組屬性。單元成績越好，可選的屬性選項越稀有華麗。

單元課程主題週次解鎖屬性選項舉例（S 級 → D 級）
unit_1先備知識簡介1–3種族性別龍族・精靈 → 植物・史萊姆
unit_2多層感知器 MLP4–6職業體型大法師・聖騎士 → 農夫
unit_3卷積神經網路 CNN7–9服飾裝備傳說級華麗 → 破損級破爛
unit_4循環神經網路 RNN10–12武器品質武器類型神器級全類型 → 木棍／石頭
unit_5深度學習進階技術13–16背景場景皇宮王座・天空之城 → 破敗廢墟
unit_6自主學習17–18表情姿勢王者風範・衝鋒 → 疲憊・蹲坐，另可選「預設（隨機生成）」
完成度＝8 份作業加權平均（總權重 55）

卡牌生成管線：五步驟接力

學生按下生成後，web-server 把角色配置＋學習數據交給 ai-worker，單 GPU 佇列一次處理一張。第一張卡免費，之後重新生成扣 5 代幣（扣款與建卡原子執行，提交失敗自動退款）。

Prompt 導演
本地路徑：Ollama qwen2.5-14b 將結構化規格改寫為連貫英文 prompt。雲端路徑：prompt_builder_cloud_v2 直出結構化 prompt，跳過 LLM 改寫。
卸載 LLM 釋放 VRAM
僅本地路徑：keep_alive=0 卸載 qwen2.5-14b（佔約 70% GPU 記憶體），否則 sd-cli 會 CUDA OOM。
文生圖
本地：sd-cli + Z-Image-Turbo（Q8_0），880×1280、steps=10、cfg=1.0，LoRA 四選一隨機。雲端：gpt-image-2 generate（全新生成）或 edit（沿用錨點卡保持角色一致性）。
縮圖
Pillow LANCZOS 產生 220×320 縮圖，供儀表板與角色大廳快速載入。
上傳＋回報
原圖＋縮圖上傳 db-storage（附完整生成 metadata），callback 通知 web-server 更新卡牌狀態。上傳失敗重試 3 次後降級本機暫存。

雙後端與三層 Fallback

🖥️ 本地後端（local）

  • Z-Image-Turbo Q8_0 GGUF＋FLUX VAE
  • LoRA 隨機：moode_fantasy／Z-Art-3／Desimulate／無
  • 零邊際成本，單張數分鐘（timeout 10 分鐘）
  • prompt 尾端固定加可讀性＋負面清單 block

☁️ 雲端後端（cloud）

  • gpt-image-2，quality=medium，b64 回傳
  • image edit：Preserve（臉／髮／種族／體型鎖定）＋ Change（風格／裝備／構圖求變）雙區塊 prompt
  • 單張約 $0.039（edit $0.049、high $0.102）
  • 圖內直接渲染暱稱、LV 徽章、稀有度字母三塊文字
失敗自動降級： ☁️ cloud edit✕ ➜ ☁️ cloud generate✕ ➜ 🖥️ local SD （fallback 原因完整記錄於 metadata 的 cloud_error）

Prompt 導演系統：讓每張卡都不一樣

生圖 prompt 不是一句話，而是一套「角色硬事實＋畫面導演規格」的組合系統：以學習數據的雜湊為種子做決定性抽選，同一組輸入永遠可重現，不同學生則風格各異。

肖像繪製所：把後端切換寫進世界觀

學生端的 /atelier 頁面用「雙畫師」敘事包裝 image_backend 系統設定——切換生圖後端不是工程術語，而是「今天輪到哪位畫師當值」。非當值畫師會灰階顯示並掛上 OFF DUTY 徽章。

🧙 教師／管理者工具

  • TronClass 成績匯入：完成度＋成績列表兩種 .xlsx，preview → commit 兩段式，匯入即冪等發放章節成就
  • 模擬生圖工作台：SIMULATION 偽學生自由組合 10 維屬性＋LV 滑桿＋seed，測試卡不進學生端；支援雲端錨點卡 image edit
  • 屬性規則編輯：S–D 各級可選選項即時 CRUD
  • 生圖歷史：後端／fallback／耗時全記錄，可 CSV 匯出，三層級刪除（隱藏／刪紀錄／連同雲端資產）
  • 批次發點數：可綁成就 key 冪等發放
